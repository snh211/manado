# 마나도 교육자료 웹사이트

## GitHub Pages 업로드
1. 저장소 최상위(root)에 `index.html`, `README.md`를 올립니다.
2. `images/` 폴더도 반드시 함께 업로드합니다. 이 폴더에는 사용자가 제공한 나인 아일랜드 사진과 호텔 사진 로딩 실패 시 표시할 대체 이미지가 있습니다.
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)`를 선택합니다.

## 이미지와 지도 안내
- 나인 아일랜드 사진은 사용자가 제공한 이미지를 `images/nain-island.png`로 저장해 사이트 내부에서 불러옵니다.
- 호텔 9곳은 전경 1장과 기본 객실 1장씩 표시합니다. 호텔 사진은 호텔 및 여행 정보 제공사의 원본 이미지 주소를 사용하므로 인터넷 연결과 원본 서버의 이미지 노출 정책에 따라 표시되지 않을 수 있습니다. 로딩에 실패하면 `images/photo-fallback.svg`가 표시됩니다.
- 지도는 OpenStreetMap 타일을 사용하고, 마나도 시내·부나켄·토모혼·탕코코·리쿠팡 위치를 표시합니다. 지도 타일과 Leaflet 라이브러리를 불러오려면 인터넷 연결이 필요합니다.
- 호텔 및 관광지 이미지의 재사용 권리는 각 원본 제공처의 이용 조건을 따릅니다.

## 수정
모든 페이지 콘텐츠와 디자인은 `index.html`에 있습니다. 이미지 파일은 `images/`에 보관합니다.

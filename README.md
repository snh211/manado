# 마나도 교육자료 웹사이트

## 반영 사항
- 메인 타이틀 아래 소개 문장 및 인천 직항·부나켄·3박 5일 태그 제거
- 메인 화면 바로가기에서 마나도 소개 / 대표 관광지 메뉴 제거, 호텔 / 일정 / 상품 코드 / FAQ 메뉴만 유지
- 메뉴 아래의 인천 직항·부나켄·3박 5일 관련 요약 배지(퀵 통계) 제거
- 기본정보 수정: 한국과 시차 1시간(마나도는 한국보다 1시간 느림), 전압·콘센트 한국과 동일, 10,000 IDR 약 750원
- 비자대행 서비스 60,000원 표시
- 관광지·호텔·권역 설명에서 요청한 안내 및 주석 문구 삭제
- 마나도 시내 관광 카드명으로 수정
- 3박 5일 일정 DAY 02 토모혼, DAY 03 부나켄으로 순서 변경
- 관광지 및 호텔 사진 URL 교체, 이미지 로딩 실패 시 대체 이미지 연결
- PC / 모바일 반응형 레이아웃

## GitHub Pages 업로드
1. GitHub 저장소(repository)를 엽니다.
2. `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다.
3. Settings → Pages로 이동합니다.
4. Build and deployment에서 `Deploy from a branch`를 선택합니다.
5. Branch `main`, Folder `/ (root)`로 설정하고 Save 합니다.
6. 만들어진 GitHub Pages 주소에서 확인합니다.

## 사진 안내
- 현재 사진은 실제 마나도 관광지와 호텔의 웹 이미지 주소를 연결합니다.
- GitHub Pages 방문자의 브라우저에서 인터넷을 통해 이미지를 불러옵니다. 원 출처가 외부 연결을 차단하거나 이미지를 삭제하면 대체 이미지가 표시되도록 처리했습니다.
- 실제 이미지 파일을 저장소 안에 포함한 오프라인형 구성은 아니므로, 완전히 독립적으로 운영하려면 이미지 파일을 내려받아 `assets/` 폴더에 넣고 경로를 로컬 파일로 바꿔야 합니다.
